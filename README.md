# Insight Plan

Downloads of Insight Plan for Windows. The app's source code is kept elsewhere; this page only holds the releases.

## Install
1. Open the [latest release](https://github.com/dvidflix/insight-plan-releases/releases/latest) and download **InsightPlan-Setup-&lt;version&gt;.exe**.
2. Run it. It installs for you only (no admin rights needed) and adds **Insight Plan** to the Start menu.
3. Windows may say "Windows protected your PC" because the installer is not signed yet: click **More info**, then **Run anyway**.

Your projects stay on your computer, in the folder you choose in the app. It works without an internet connection.

## Updates
The app checks this page for a new version. When there is one, **Update available** appears at the top of the app: click it, then
**Restart and update**. Only the app part is downloaded (a few MB); your projects are not touched.

## The other files of a release
- `InsightPlan-app-<version>.zip` and `latest.json`: the update the app downloads by itself (signed). You do not need to download them.
